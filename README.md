# WeatherApp

WeatherApp is an Android application built with Kotlin that allows users to get current weather information for any city or country. By integrating with WeatherAPI, the app provides real-time data including temperature (in Celsius), current weather conditions, humidity, wind speed, UV index, and more—all displayed in an easy-to-read format.

## Features

- **City/Country Search:**  
  Users can enter any city or country in the search box to retrieve weather details.

- **Comprehensive Weather Details:**  
  After searching, the app displays:
  - City and country name
  - Temperature (in Celsius)
  - Current condition icon and text
  - Humidity levels
  - Wind speed
  - UV index
  - Precipitation (if applicable) or any additional weather metrics
  - Local time and date

- **Clean and Intuitive Interface:**  
  Designed with user experience in mind, ensuring that weather information is clear and accessible.

## Built With

- **Kotlin:** Main programming language for Android development.
- **WeatherAPI:** Provides up-to-date weather information.

## Installation

1. **Clone the Repository:**
   ```
   git clone https://github.com/Kutubuddin-Rasel/Weather-App.git
   ```

2. **Open in Android Studio:**  
   Open the project in Android Studio to build and run the application.

3. **Configure WeatherAPI:**
   - Sign up for an API key at [WeatherAPI](https://api.weatherapi.com/).
   - Add your API key to the appropriate configuration file in the project.

4. **Build and Run:**  
   Build the project in Android Studio and run the app on an emulator or a physical device.

## Usage

- **Search Weather:**  
  Launch the app and use the search box on the home screen to enter a city or country name. The app will display detailed weather information for the searched location.
